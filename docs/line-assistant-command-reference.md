# LINE 小助手｜歡迎詞快捷指令清單

本文件為施工中的指令規格，**不是已上線功能**。後續應在 JLY 管理後台「LINE 小助手指令大全」提供手機可查閱的相同內容，並依實際程式更新。

## 歡迎詞

| 指令 | 用途 |
| --- | --- |
| `助手 設定歡迎詞 歡迎加入！請先閱讀記事本。` | 將指令後所有文字設為本群新人歡迎詞，允許換行及 Emoji |
| `助手 查看歡迎詞` | 查看本群目前生效的歡迎詞 |
| `助手 恢復預設歡迎詞` | 清除本群自訂歡迎詞，恢復系統預設 |

## 權限與呈現

- 未綁定車團的一般 LINE 群組：群內任何成員可在群組內輸入上述指令，不提供設定按鈕或一般群員後台入口。
- 已綁定車團的群組：僅車團主揪或授權管理者可修改或恢復歡迎詞；原有 DM、玩家報名、行事曆按鈕必須保留。
- 群組只回覆簡短的設定結果，不張貼完整修改歷史。
- 所有修改歷史（群組、LINE 修改者、伺服器時間、前後文字）集中供 JLY 系統管理員於「LINE 群組管理」後台查看，不與 Car ID 綁死。
- 快捷指令須以經 LINE webhook 簽章驗證的群組訊息為準；不得接受外部偽造 groupId 或跨群修改。
- 後台「LINE 小助手指令大全」應彙整既有已實作的車團綁定、報名、DM／男女位、行前提醒、記帳指令；要標註各指令是否已上線，避免把規劃中的指令誤標為可用。

## 施工邊界

- 繼續使用現有 LINE webhook、group binding、Car、Person／Identity，不建立第二套。
- 不修改 main、PR #330、Production 或正式 Firestore；待獨立分支實作、測試、驗收後另行核准。
