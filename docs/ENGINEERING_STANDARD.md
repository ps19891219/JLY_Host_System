# 1. 文件目的

本文件定義 JLY Host System 的程式架構、資料模型、
檔案拆分方式、命名規則與開發流程。

所有新功能、舊功能重構與資料模型設計，
原則上都應遵守本文件。

本文件的主要目標是：

- 保持程式碼容易閱讀
- 避免單一檔案過度膨脹
- 降低功能之間互相干擾
- 讓專案未來可以持續擴充
- 讓半年或數年後仍能快速理解架構
- 為未來多人協作預留空間

---

# 2. 專案核心方向

JLY Host System 將依照以下階段發展：

## 第一階段

主揪個人工具。

主要功能包含：

- 建立車團
- 管理車團
- 玩家報名
- 玩家審核
- 座位安排
- 工作人員管理
- 車團歷史紀錄
- 招募與提醒文案
- 個人劇本紀錄

## 第二階段

工作室與 DM 協作系統。

主要功能包含：

- 工作室資料
- 工作室人員
- DM 排班
- 劇本資料庫
- 主揪與工作室合作
- 收款與轉付紀錄
- 權限管理

## 第三階段

玩家與劇本社群。

主要功能可能包含：

- 玩家個人頁
- 好友與關係
- 共同車次
- 劇本回憶
- 心情與心得
- 玩家、主揪、DM 與工作室之間的串聯

# 3. 核心資料原則

## 3.1 所有人共用 Member

系統中的所有人，都必須來自同一個 Member 資料來源。

例如：

- 玩家
- 主揪
- 工作人員
- DM
- 工作室負責人
- 工作室員工

這些不是不同的人員資料庫，
而是同一個 Member 擁有不同身份或角色。
